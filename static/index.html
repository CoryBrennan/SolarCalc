ⓘ Each row's output circuit ampacity is the sum of that row's input fuse ratings, not raw Isc × 1.25 × inputs — matching how a combiner's output circuit is conventionally sized once each input is individually fused. Each row picks its own module (from Module Spec's SKU catalog) and sizes its input fuse off that module's own Isc — a row's fuse is not tied to whatever SKU is currently selected in Module Spec. The max series fuse rating cap is still shared across rows (same module family, so the same physical limit applies regardless of wattage bin) — if it forces a row's fuse below 125% of that row's Isc, the fuse shows red. OCPD Sizing's "DC combiner output circuit" option lets you pick which row to size a breaker/fuse for.
