Getting the site onto the ASHRAE map

  1. Click Copy coordinates above — that puts lat, lon in decimal degrees on the clipboard, which is the format the map's search box expects.
  2. Open the map with the link above. It lands on the MAP tab.
  3. Paste into the Lat&Lon (xx.xx;yy.yy) or WMO box at the top-left and press the magnifier. The map recentres and drops a pin.
  4. Alternatively, skip the box entirely: right-click the site location on the map. The nearest weather stations appear in the left-hand list, lettered A, B, C… with their distances.
  5. Pick the ASHRAE edition (2009 / 2013 / 2017 / 2021 / 2025) and the SI / IP unit radio before reading values — this panel works in °C (SI).

Copying a station's link back here

  1. Click a station in the left-hand list (or its lettered pin). Its full data table loads below the map.
  2. Look to the right of the station name for the link box — the long http://ashrae-meteo.info/index.php?lat=…&lng=…&wmo=… URL — and use the chain-link icon beside it to copy it.
  3. Paste it into Station links from the map below, one per line. Prefix a readable name if you want: ST LOUIS REGIONAL AP, IL | http://…
  4. Click Parse links, then pick the station from the dropdown. Distance and grade are computed here from the site coordinates.
  5. For the full data set, select the station's whole data table on the map page, copy it, and paste it into Selected station — full ASHRAE data set at the bottom of this panel.
